# Code of Conduct

## Our standards

We want Kindcaddy to be a welcoming and productive place to collaborate. We commit to:

- Being respectful and considerate in all communication.
- Welcoming newcomers; remembering everyone was new to a codebase once.
- Focusing critique on code and ideas, not on the people behind them.
- Giving and gracefully accepting constructive feedback.
- Assuming good faith when intent is unclear; asking before accusing.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, sustained disruption of discussions, and publishing others' private information without consent.

## Scope

This Code of Conduct applies in all project spaces — issues, pull requests, code comments, and any official communication channels — and to behavior outside those spaces that affects the project's community.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards and will take appropriate action in response to behavior that violates them. Possible actions include:

1. A private warning explaining the concern.
2. A public correction.
3. Temporary or permanent removal from project spaces.

To report a concern, contact the maintainers privately (see [`SECURITY.md`](./SECURITY.md) for the contact channel — please indicate it's a conduct report, not a security report). Reports will be handled confidentially.
